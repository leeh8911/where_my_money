# Discord 출력 포맷 (초안)

## 1) 오늘 지출 요약
```
[where_my_money] 오늘 지출 요약
- 총액: 42,050원
- 카드별: 생활비카드 20,500원 / 고정비카드 21,550원
- 카테고리: 식비 20,500원 / 교통 1,550원 / 쇼핑(할부 당월분) 20,000원
```

## 2) 결제 예정
```
[where_my_money] 결제 예정
- 생활비카드: D-3, 예상 305,000원
```
