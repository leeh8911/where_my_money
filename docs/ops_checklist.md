# 운영 체크리스트 (초안)

## 배포 전
- [ ] `.env` 값 확인 (TIMEZONE/DB_URL)
- [ ] API health check 확인
- [ ] 핵심 테스트 통과

## 데이터 불일치 발생 시
- [ ] 원천 거래 데이터와 tx_id 대조
- [ ] 취소(original_tx_id) 매핑 확인
- [ ] 할부개월수 값 확인
- [ ] 카드 billing_day 설정 확인

## 장애 대응
- [ ] 최근 배포 커밋 확인
- [ ] 에러 로그(code/message) 수집
- [ ] 임시 우회(동기화 중지/읽기전용 모드) 적용
- [ ] 원인/조치 내용 Notion 로그 기록
